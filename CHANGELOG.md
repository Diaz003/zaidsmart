## [0.2.0] - 2026-04-11

### Added
- 🚀 **Lanzamiento inicial completo** de ZAIDSMART
- 🤖 Sistema multiagente con CrewAI jerárquico
- 🎯 4 agentes especializados: Script, Assets, Sonidos, Escenas
- 🌐 Integración completa con OpenRouter
- 🛡️ Manejo robusto de límites de tasa (429) con fallback
- 🎨 Dashboard web dark mode con FastAPI
- 💻 Interfaz terminal interactiva con Rich
- 💾 Persistencia SQLite con aiosqlite
- 🔄 Sistema de refresco automático de modelos
- 📊 Monitoreo en tiempo real del progreso
- 🧪 Suite completa de pruebas
- 📦 CI/CD con GitHub Actions
- 📚 Documentación completa y README profesional

### Changed
- Arquitectura modular para mejor mantenibilidad
- Optimización de dependencias para rendimiento

### Technical
- Python 3.12+ requerido
- Estructura de proyecto escalable
- Configuración de entorno con .env
- Scripts de inicio automatizados

## [0.1.0] - 2026-04-01

### Added
- Concepto inicial y prototipo
